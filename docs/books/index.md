# Computer science, from the inside out

Three books, each one course from the first idea to the questions researchers are still working on. Read a book in
order: every chapter needs only the ones before it. Nothing is a black box: every method is built from scratch in
code you can run, and every claim comes with its reason.

**Books or topic pages?** The [topic pages](../index.md#topics) are a reference: one algorithm per page, with code in
Python, Java and C++ and an animation. A book is a course that teaches you to understand, prove and invent
algorithms and learning systems yourself. The chapters link to the topic pages wherever one exists.

## How a chapter works

- **It opens with a box** saying what you will learn, which chapters you need first, and which sections are
  beginner, intermediate, advanced or expert. Skip the harder sections on a first read and come back later.
- **Every idea comes with its reason.** Algorithms are proved correct and their running time is worked out; where a
  proof is too long for the page, the chapter says so, gives the idea, and names where the full proof is.
- **Worked examples** are traced by hand, step by step.
- **Code you can run.** Each program is in Python, small, tested, and printed with its real output.
- **Check yourself** ends each chapter: questions from easy to hard, each with a full worked answer folded under it.
  Try first, then open it.
