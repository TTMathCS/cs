# Machine learning

*A book in 23 chapters, from fitting a straight line to transformers, diffusion models and the open questions of the
field. Nothing is a black box: every method is built from scratch in Python and NumPy, derived on paper, tested on
data you can see, and followed by questions whose answers are folded underneath.*

## How to read it

- **In order.** Each chapter needs only the ones before it; the **Next** link at the end of every chapter walks you
  through.
- **Levels inside a chapter.** The box at the top of each chapter says which sections are beginner, intermediate,
  advanced or expert. On a first read, skip the harder sections and come back later.
- **Code.** Every program is short Python 3 with NumPy, and nothing else: no machine-learning library does the work
  for you. Each chapter says in one line which library does the same thing in real projects.
- **Math.** Chapter 3 builds the vectors, derivatives and probability the book needs. The
  [math books](https://math.akadian.ca/books/) (linear algebra, calculus, probability, statistics) go further.
  The [Algorithms book](../algorithms/index.md) covers the data structures and the analysis of running time.
- **Do the questions.** Try each one before opening its answer.

## Three ways in

- **New to the subject:** read chapters 1 to 8. That is the core of every first course: data, linear and logistic
  models, optimization, honest evaluation and overfitting, with every formula derived.
- **You want deep learning:** read chapters 3, 5 and 6, then go straight to chapters 15 to 20.
- **You know the methods and want to know why they work:** start at chapter 21, then read 22 and 23, and use the
  glossary to look back.
