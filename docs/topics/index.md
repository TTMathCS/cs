# Topics

*Start from the job you want to do. Each guide is one page in four parts, so you can stop at the part you need.*

## What is here

Topics holds two kinds of page, both reached from the menu on the left:

| Group | What is in it |
|---|---|
| **Step-by-step guides** | one job each (sorting, shortest routes, language models), in four parts, below |
| **[Algorithm reference](../algorithms/index.md)** | one page per algorithm, grouped by kind: sorting, searching, data structures, graphs, dynamic programming and more |

The longer reading, the three [books](../books/index.md), is under **Books**.

## How each guide is laid out

| Part | Level | What it holds |
|---|---|---|
| **In one minute** | Beginner | the idea in plain words |
| **Do it** | Intermediate | working code and the library calls to use |
| **Expert** | Expert | which algorithm when, with its cost; the implementations; common mistakes; best practices |
| **Now and next** | Expert: the latest research | recent results and open questions, with the date it was checked |

Each guide stays short and links to the [Algorithm reference](../algorithms/index.md) pages and the [Books](../books/index.md) for depth.
